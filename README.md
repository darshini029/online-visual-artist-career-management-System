# KIRA — Creative Career Studio for Adult Artists

KIRA is the latest working frontend preview for an 18+ professional artist audience. It keeps the visual/editorial direction and interactive workflow while adding artwork, artist profiles, journal/blog content, jobs, publishing, Review Room, community and My Studio.

## Run
cd server
npm install
npm run dev

Open http://localhost:5000

The server uses `PORT` from the environment. For this preview, if Express is not installed, it automatically falls back to Node's built-in HTTP server so the homepage can still be previewed.
